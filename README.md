# Ireneo Atenta Portfolio

A personal portfolio website showcasing projects, certifications, work experience, and contact information.

## Overview

This portfolio is built as a single-page React app to present:

- A professional profile and summary
- Featured projects with detailed modals
- Certificates and achievements
- Contact information and social media links
- Responsive layout for desktop and mobile devices

## Tech Stack

- HTML5
- CSS3
- JavaScript
- React 18
- Babel Standalone
- Font Awesome

## Project Structure

```text
me.portfolio/
├── index.html
├── script.js
├── style.css
├── images/
│   ├── projects/
│   └── certificates/
├── README.md
└── .gitignore
```

## Features

- Responsive navigation menu
- Hero section with personal branding
- About section with professional background and skills
- Project cards with modal detail views
- Certificates gallery with verification details
- Contact form UI
- Dark mode support preparation

## Local Development

1. Clone the repository
2. Open the project folder in your terminal
3. Start a local web server:

```bash
python -m http.server 8000
```

4. Open your browser and visit:

```text
http://localhost:8000/
```
